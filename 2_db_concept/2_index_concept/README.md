## Response Section

ดัชนี B-tree บน (school_id, grade) ช่วยให้ฐานข้อมูลค้นหาห้องของโรงเรียนหนึ่งในชั้นปีที่ระบุได้โดยอ่านเฉพาะช่วงที่ตรงกัน และอาจใช้ลำดับของดัชนีช่วยจัดเรียงผลได้ ดัชนีแบบ unique ยังบังคับให้ค่าหรือชุดค่าที่เลือกไม่ซ้ำกัน

ต้นทุนคือพื้นที่ดิสก์และหน่วยความจำ รวมถึงเวลาเพิ่มเมื่อ insert, delete หรือแก้คอลัมน์ที่มีดัชนี ลำดับคอลัมน์มีผล ดัชนีข้างต้นเหมาะกับการกรองโรงเรียน แต่การกรองชั้นปีอย่างเดียวอาจยังต้องอ่านข้อมูลจำนวนมาก ถ้าตารางเล็กหรือเงื่อนไขคืนข้อมูลเกือบทั้งหมด ตัววางแผนอาจเลือกสแกนตาราง ตรวจแผนด้วย EXPLAIN และวัดทั้งเวลาอ่านและเขียนด้วยข้อมูลขนาดใกล้เคียงของจริงก่อนเพิ่มดัชนี
